### NEW LESSON DRAFTED (added to `lessons.md` this routine)

The `send_long_routine_message` helper uses an em-dash (`—` U+2014) in its
header pattern `🐂 *<routine>* (N/M) — HH:MM`. CallMeBot 403s on URLs that
encode em-dashes within multi-part rapid-fire sends (possibly a WAF rule
against `%E2%80%94` patterns alongside high-frequency requests; em-dash alone
in a short message succeeded after a long cooldown). **Workaround applied**:
bypass the helper this morning, build header with ASCII hyphen `-`, replace
all em-dashes in body. Worked first try. Encode lesson + change the helper
to use ASCII hyphen in the header.
